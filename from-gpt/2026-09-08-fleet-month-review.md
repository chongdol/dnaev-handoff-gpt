# รวมรถ → ปฏิทินรายคัน: ขอ C ตรวจข้อมูลและลดขั้นตอน

คำสั่งเจ้าของล่าสุด: รวมรถทุกคัน ภาพรุ่นจริงสไตล์ 3D น่ารัก แสดงรหัส DNA รุ่น ทะเบียนจริง สถานะว่าง/ไม่ว่าง แตะรถดูเดือนเต็มและติ๊กวันที่มีจอง อ้างอิงเรฟเดิม ใช้ง่ายสำหรับคนไม่ถนัดแอป ให้ GPT กับ C ตรวจร่วมกัน

## ขอข้อเท็จจริงก่อนใส่ในแอป

1. เจ้าของกล่าว DNA 1–14 แต่ PRIVATE fleet-catalog มี 14 แถว / 12 active และ DNA code ยืนยันเพียง 4 คัน กรุณายืนยันการจับคู่รหัสจริงทุกคัน อย่าสร้างรหัสแทนเจ้าของ ส่งตาราง carId / dnaCode / model / plateClean / province / active / color / photoUrl ในไฟล์ PRIVATE เดิมเท่านั้น
2. สองคัน inactive ยังอยู่ในคลังให้แสดงเป็น "พักใช้งาน" หรือขาย/ย้ายออกแล้ว? Chery Q เป็นรถเพิ่มหรือยังไม่อยู่ในคลัง? กรุณาส่งภาพอ้างอิงรุ่น/สีที่ขาดแบบไม่มีทะเบียน/บุคคลสำหรับสร้างภาพจำลอง
3. API calendar v2 deploy แล้วหรือยัง? ขอระบุ endpoint/version จริง และเส้นทางล็อกอินทีมที่ใช้ได้ใน native preview โดยไม่ส่ง secrets หากยังไม่พร้อม ขอ snapshot read-only เดือนปัจจุบันและเดือนถัดไปใน PRIVATE แยกจาก demo: generatedAt, requestedRange, carId, bookings status/startAt/endAt, blocks/conflicts โดยตัดชื่อ/ข้อมูลลูกค้าออก
4. สถานะ availability ปัจจุบันรวม car_blocks แล้วหรือยัง? หากไม่รวม จอจะบอก "รอตรวจคิว" แทนรับประกันว่าง

## ข้อเสนอการใช้งาน (ขอ C วิจารณ์/แก้ช่องที่ขาด)

- ทางเข้าเดียว "รถและปฏิทิน" ใช้คลังรถชุดเดียวกับตัวเลือกรถในใบจอง ไม่สร้างข้อมูลรถซ้ำ
- เปิดมาเห็นรถ ภาพ รุ่น รหัส ทะเบียน สถานะของวัน/ช่วงที่เลือก ชัดเจนว่าข้อมูลอัปเดตเมื่อไร
- แตะรถหนึ่งครั้ง → เดือนเต็ม: ✓ มีจอง, จุด/ป้ายรับ–คืนสำหรับ partial, พักซ่อมและคิวชนแยกชัด ไม่พึ่งสีอย่างเดียว
- แตะวัน → งานและเวลารับ–คืน กดรายการไปใบจองเดิมได้ ไม่ให้กรอกข้อมูลซ้ำ
- เลือกวันว่าง → เตรียมร่างพร้อมรถ/วัน โดยยังให้ server ตรวจระดับนาทีก่อนสร้างจริง
- โหลดไม่ได้/403/ข้อมูลเก่า/รถพักใช้งานต้องไม่แสดง "ว่าง" การสาธิตแยกป้ายจากข้อมูลจริงเสมอ
- ภาพเป็น 3D illustration ของรุ่น/สี ใช้ซ้ำเมื่อรุ่นสีเดียวกัน ป้ายทะเบียนมาจากข้อมูลจริงใน UI ไม่ฝังลงภาพและไม่ใช้ภาพบอกตัวตนคัน

รับข้อเสนอ one inbox ล่าสุดแล้ว รอบนี้ทำรถและปฏิทินเป็นทางเข้าย่อยเดียว ไม่เพิ่มแดชบอร์ด/ฟอร์มซ้ำ ส่วน AI inbox เป็นงานถัดไปตามแผนรวม
