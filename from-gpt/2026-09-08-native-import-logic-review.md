# Native import logic พร้อมตรวจ — 8 ก.ย. 2569

ต่อจาก native0.9 checkpoint: private commit 7b559a8. ไม่แก้แบบหน้าจอที่ส่งเจ้าของตรวจ ไม่เชื่อม production หรือส่งภาพ/ข้อความลูกค้าออกไป.

พอร์ตตัวอ่านใบจอง0.7เป็น Foundation Swift แล้ว พร้อม per-field sourceID/excerpt และตัวรวมหลายเอกสาร. ยังไม่ต่อผลเป็นการ์ดกรอกอัตโนมัติ จึงไม่อ้างว่า native import UX เสร็จ.

เคสที่ล็อกด้วยเทสต์:
- ตัวอย่างรับ12ส.ค.69คืน19ส.ค.69เวลา16:30 → ค.ศ.2026, รับ/คืน16:30, returnDeadline17:00เป็นclaimแยก.
- ค่าส่ง250/500 → conflict; ไม่เลือกยอดเอง. นำเข้าใบที่สาม300 → ยังconflictทั้ง3ยอด.
- บรรทัด "ค่าส่ง500 รวม15,250" → ยอดรวม15,250 ไม่หยิบค่าบริการข้างกันเป็นอีกยอดรวม.
- เวลา25:00ไม่ถูกอ่านบางส่วนเป็น05:00. ไม่เติม09:00. JSON Booleanไม่กลายเป็นจำนวนเงิน1; numericdate/วันจ่ายผิดปฏิทิน/feepercent6ไม่ผ่าน.
- เงินทศนิยมคงค่า; จำนวนเงินติดลบไม่กลายเป็นบวก. ไม่คำนวณราคารวมแทนserver.
- Duplicate conflictจากJSONไม่ทำแอปcrash; sourceภายนอกไม่ปลอมเป็นhuman/sourceIDจริง. พี่แก้เองชนะค่าที่นำเข้า.
- Speech partialแก้เฉพาะส่วนที่มาจากเสียง; คนพิมพ์แก้ระหว่างฟังแล้วผลเสียงเก่าห้ามทับ. Scanเก็บเลขหน้าเดิมแม้บางหน้าอ่านไม่สำเร็จ; tempลบหลังOCR/ผลที่มาหลังปิดกล้องไม่เปิดร่างเอง.

ผลตรวจ: parser4กลุ่มผ่าน, speech-draft5เคสผ่าน, iOS17 capture typecheckผ่านไม่มีwarning, XCTestส่วนที่ได้รับผล2เคสผ่าน27.334s. Hardwareกล้อง/เสียงยังต้องลองiPhoneจริง.
