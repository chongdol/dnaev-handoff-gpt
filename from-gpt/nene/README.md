สำเนาต้นฉบับพื้นม่วงอยู่ `originals/` ชื่อเดียวกัน เก็บไว้เพื่อส่งต้นฉบับครบ ไม่ใช้เป็นรูปโปร่งใส ทุกไฟล์คัดลอกตรงจากชุดเดิม ไม่มี resize หรือ redraw ตรวจ alpha ของชุดโปร่งใสพบมุมทั้งสี่เป็น 0 และมี foreground 255 พร้อมขอบกึ่งโปร่งใส ไม่มีข้อความ โลโก้ หรือข้อมูลลูกค้า

หลักฐานงานเดิม ASSET-DELIVERY / ADDITIONAL-POSE-DELIVERY ระบุเคยตรวจภาพและบรรจุ asset catalog แล้ว แต่ไม่พบการอนุมัติแยกครบห้าท่าในหลักฐานที่อ่าน จึงไม่อ้างว่าเจ้าของอนุมัติรายไฟล์ทั้งหมด ขอ C ตรวจเข้ากับเนเน่เวอร์ชันปัจจุบันก่อนแทนใช้

ชุดนี้รองรับหลายฟีเจอร์ แต่ยังไม่ใช่ครบทุกท่าที่ C ขอ: checklist/contract แบบเฉพาะ, waiting, oops, empty, money และ face สามอารมณ์ยังไม่มีไฟล์แยกในชุดนี้ ไม่ใช้ชื่อท่าแทนความหมายภาพที่ไม่ตรง

Alpha channel มีทั้ง 0 และ 255 ในทั้งสี่ไฟล์ แต่การมี alpha ไม่รับประกันว่าพื้นหลังถูกลบสะอาดทั้งหมด ห้ามถือว่าทั้งชุดผ่านสเปก production โดยอัตโนมัติ

## ขอ C ตรวจต่อ

- เทียบกับ `public/v2/nene.png` และ `public/home/nene-face.png` ของระบบปัจจุบันก่อนแทนภาพ: ฝั่งนี้ยังไม่ได้ตรวจสองไฟล์จริง จึงไม่ยืนยันว่าไฟล์ตรงกันทุกพิกเซล
- เลือกใช้เฉพาะรูปที่ตรงตัวละครและพื้นหลังจริง; ขนาดต่ำกว่าสเปกหรือพื้นตกค้างให้รายงานกลับก่อนปรับ
- รูปใหม่/การแก้ภาพต้องให้เจ้าของตรวจ; งานนี้เป็นส่งต้นฉบับที่มี ไม่ใช่อนุมัติชุดท่าใหม่
- ไม่มีข้อมูลลูกค้า ทะเบียน หรือเอกสารจริงในชุดภาพนี้ ไม่มีโค้ดแอปหรือข้อมูลระบบแนบมา
