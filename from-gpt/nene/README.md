# เนเน่ — ชุดภาพเดิมจากฝั่งดีไซน์

ส่ง 5 ตุลาคม 2026 ตาม `to-gpt/2026-10-05-request-nene-secretary-images.md` และคำสั่งเจ้าของให้ส่งชุดที่ออกแบบไว้ ไม่มีการสร้างใหม่ ขยายภาพ หรือตัดพื้นหลังใหม่ในรอบนี้ ไฟล์คัดลอกตรงต้นฉบับ ตรวจ SHA-256 ตรงกันทุกไฟล์ ดู `manifest.json`

## รูปแยกที่มีอยู่

| ไฟล์ | ท่า / การใช้ | ขนาด | สถานะและข้อจำกัด |
|---|---|---|---|
| nene-hello.png | ยิ้มโบกมือ ใช้ต้อนรับ | 640×640 | PNG alpha จากชุดประกอบหน้าแรกเดิม; ต่ำกว่า 1024 และขอบผมมีรอยตัด ไม่ควรขยายเป็นต้นฉบับใหม่ |

Alpha channel มีทั้ง 0 และ 255 ในทั้งสี่ไฟล์ แต่การมี alpha ไม่รับประกันว่าพื้นหลังถูกลบสะอาดทั้งหมด ห้ามถือว่าทั้งชุดผ่านสเปก production โดยอัตโนมัติ

## ต้นแบบอ้างอิง — ไม่วางเป็นภาพลอยในแอปโดยตรง

| ไฟล์ | ความหมาย / การอนุมัติ |
|---|---|
| references/nene-approved-expressions.png | แผ่นต้นแบบที่เจ้าของเลือก: ยิ้ม กำลังคิด ขอตรวจอีกนิด และปลื้มตาหัวใจ; มีข้อความและโลโก้ เป็น reference เท่านั้น ไม่ใช่ภาพแยกโปร่งใส |
| references/nene-hello-original.png | ต้นฉบับเดี่ยวโบกมือความละเอียดสูง พื้นม่วง มีอยู่จากงาน motion; ไม่พบหลักฐานอนุมัติไฟล์นี้แยกจากต้นแบบ จึงไม่ติดป้ายว่าผ่านแล้ว |

รูปลักษณ์ต้นแบบ: ผมบ๊อบม่วง กิ๊บสายฟ้าเหลือง ขอบหน้าครีม หน้ากรม ตาฟ้า แก้มชมพู ปากยิ้มเล็ก ไหล่ชมพู วงคอมินต์ รักษาสัดส่วนเดิม ไม่ยืดบีบ

## ยังไม่มีไฟล์เดี่ยวพร้อมส่ง

`nene-reading`, `nene-done`, `nene-checklist`, `nene-contract`, `nene-waiting`, `nene-oops`, `nene-empty`, `nene-money`, `nene-chat` และ `nene-face-*` สามอารมณ์: ยังไม่พบต้นฉบับแยกที่ตรงสเปกในชุดที่ตรวจ สีหน้าบางส่วนมีเฉพาะแผ่น reference จึงไม่ครอปหรือสร้างใหม่แทนโดยพลการ

## ขอ C ตรวจต่อ

- เทียบกับ `public/v2/nene.png` และ `public/home/nene-face.png` ของระบบปัจจุบันก่อนแทนภาพ: ฝั่งนี้ยังไม่ได้ตรวจสองไฟล์จริง จึงไม่ยืนยันว่าไฟล์ตรงกันทุกพิกเซล
- เลือกใช้เฉพาะรูปที่ตรงตัวละครและพื้นหลังจริง; ขนาดต่ำกว่าสเปกหรือพื้นตกค้างให้รายงานกลับก่อนปรับ
- รูปใหม่/การแก้ภาพต้องให้เจ้าของตรวจ; งานนี้เป็นส่งต้นฉบับที่มี ไม่ใช่อนุมัติชุดท่าใหม่
- ไม่มีข้อมูลลูกค้า ทะเบียน หรือเอกสารจริงในชุดภาพนี้ ไม่มีโค้ดแอปหรือข้อมูลระบบแนบมา
