# แจ้งทีมออกแบบ — เพิ่มช่อง "ชื่อที่ให้ทีมเห็น" ในหน้า `/login` (ไม่มีในแบบเดิม)

หน้า `/login` ประกอบตามแบบที่เจ้าของอนุมัติ 8 ก.ย. 69 (`login-otp-design-v1`) ครบทุกจุดแล้ว
แต่มีช่องเดียวที่**ต้องเพิ่มนอกแบบ** เพราะ backend บังคับไว้จริง ไม่ใช่การตัดสินใจฝั่งดีไซน์:

## ทำไมต้องมี
`POST /api/auth/verify` (เส้นยืนยัน OTP จริงที่ deploy อยู่แล้ว) **บังคับส่ง `name` มาด้วยเสมอ**
— ถ้าไม่มี `name` จะได้ `400` ทุกครั้ง ไม่มีทางข้ามได้ ชื่อนี้คือชื่อที่จะไปโชว์ในการ์ดแจ้งเตือนทีม
("เมย์แก้ไข Booking #123" ฯลฯ) เทียบเท่ากับ `displayName` ที่ใช้อยู่ทั่วแอปเว็บเดิม

## ใส่ตรงไหน
เพิ่มเป็น**แถวที่สอง**ในการ์ดล็อกอิน (ระหว่างช่องอีเมล กับช่องรหัสผ่านที่ปิดใช้งานอยู่แล้ว)
ไม่ได้เปลี่ยนโครง/ระยะ/สีของแบบเดิมจุดอื่นเลย ใช้ชุดไอคอน+สไตล์แถวเดียวกับช่องอื่นในการ์ด:

- ไอคอน: ☺ พื้นมิ้นต์ (ชุดสีเดียวกับที่แบบใช้อยู่ในการ์ดนี้)
- label เล็กบนช่อง: "ชื่อที่ให้ทีมเห็น"
- placeholder: "เช่น เมย์"
- บังคับกรอกก่อนกดขอรหัส — ไม่กรอกขึ้นข้อความเตือน "กรุณากรอกชื่อที่อยากให้ทีมเห็นด้วย" สีแดงใต้การ์ด (ใช้ note tone เดียวกับ error อื่นในจอนี้)

## ไม่กระทบอะไร
ลำดับ อีเมล → รหัสผ่าน(ปิด) → ปุ่มเข้าสู่ระบบ → OTP ยังเหมือนเดิมทุกจุด ไม่มีจอใหม่ ไม่มี step ใหม่
แค่แทรกช่องเดียวตรงกลาง — ถ้าทีมออกแบบอยากปรับ label/ตำแหน่ง/ไอคอนให้สวยกว่านี้ ส่งกลับมาที่ `from-gpt/` ได้เลย โค้ดปัจจุบันยึดสไตล์การ์ดเดิมไว้ก่อนเพื่อไม่ให้จอค้างไม่ให้ทีมใช้งาน
