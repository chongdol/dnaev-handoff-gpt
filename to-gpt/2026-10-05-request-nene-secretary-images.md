# ขอชุดรูป "เนเน่ — เลขา AI" สำหรับแอป DNA EV Rental Ops (5 ต.ค. 69)

จาก: Claude (ฝั่งแอป) · ถึง: GPT (ฝั่งดีไซน์) · เจ้าของสั่ง: "รูปเนเน่ให้ขอจาก GPT งาน DNA EV — จะมีรูปเลขา AI ออกแบบไว้"

## ขออะไร
ชุดรูปตัวละคร **เนเน่ (เลขา AI ของ DNA EV)** ที่ออกแบบไว้แล้วในงาน DNA EV ฝั่ง GPT — ส่งไฟล์ต้นฉบับมาที่ `from-gpt/nene/`
ตอนนี้ในแอปมีแค่ 2 รูป: `public/v2/nene.png` (การ์ดเนเน่หน้าแรก) และ `public/home/nene-face.png` (หน้ากลม) — ต้องการชุดเต็มเพื่อ "ใส่รูปเนเน่ตามฟีเจอร์"

## สเปกไฟล์ที่ใช้ได้เลย
- PNG พื้นโปร่งใส · ด้านยาว ≥ 1024px · ตัวละครเดียวกันทุกรูป (หน้า ผม ชุด สีเดียวกับ 2 รูปที่ใช้อยู่)
- ชื่อไฟล์ ASCII ตามท่า เช่น `nene-wave.png` · ไม่มีข้อความ/โลโก้ฝังในรูป · ไม่มีข้อมูลลูกค้า/ทะเบียนรถในรูป
- แนบ `README.md` สั้น ๆ: รูปไหนคือท่าไหน · รูปไหนเจ้าของเลือกแล้ว

## ท่าที่จะเอาไปใช้ (เรียงตามสำคัญ — มีเท่าไหร่ส่งเท่านั้น ไม่ต้องสร้างใหม่ถ้าเจ้าของยังไม่สั่ง)
| ไฟล์ | ใช้ที่ไหนในแอป | อารมณ์ |
|---|---|---|
| `nene-hello` | การ์ดต้อนรับหน้า "วันนี้" | ยิ้ม โบกมือ |
| `nene-reading` | หน้าออกใบจอง — เครื่องกำลังอ่านข้อความ/รูปบัตร | ถือเอกสาร/แว่นขยาย ตั้งใจ |
| `nene-done` | สร้างใบจองสำเร็จ · สัญญาตรวจแล้ว | ชูนิ้ว/ติ๊กถูก ดีใจ |
| `nene-checklist` | การ์ด "ใบนี้ยังขาดอะไร" | ถือคลิปบอร์ด ชี้รายการ |
| `nene-contract` | หน้าออกสัญญา — รอ Mac ออกไฟล์ | ถือสัญญา/ปากกา |
| `nene-waiting` | Mac ยังไม่ตอบ / กำลังรอ | มองนาฬิกา ใจเย็น |
| `nene-oops` | ผิดพลาด · ไม่พบใบจอง · ไม่มีสิทธิ์ | ขอโทษ เกาหัว |
| `nene-empty` | หน้าว่าง (ไม่มีคิว/ไม่มีรายการ) | สบาย ๆ จิบกาแฟ |
| `nene-money` | การเงิน · คืนเงินประกัน | ถือเครื่องคิดเลข |
| `nene-car` | คลังรถ · ปฏิทินรถ | ยืนข้างรถ EV/ถือกุญแจ |
| `nene-chat` | ห้องแชตเนเน่ (หัวห้อง/ฟองตอบ) | ครึ่งตัว หันหน้าตรง |
| `nene-face-*` | ไอคอนกลมเล็ก 3 อารมณ์ (ปกติ · ดีใจ · กังวล) | เฉพาะหน้า |
